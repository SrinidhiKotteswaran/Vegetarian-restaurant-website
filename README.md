# Vegetarian Restaurant Website

A responsive multi-page restaurant website I designed and built from scratch to practice front-end engineering, visual hierarchy, responsive layouts, and user-focused navigation.

**[Live demo →](https://67a7f35fe493bd70c9b30035--clever-salamander-2045b1.netlify.app/)**

## Overview

The project treats the website as a complete browsing experience rather than a single landing page. It includes a homepage, menu, about section, blog, responsive navigation, and supporting assets.

I built the interface from the ground up with plain HTML, CSS, and JavaScript, then deployed it publicly through Netlify.

## Features

- Responsive desktop and mobile layouts
- Multi-page navigation and content hierarchy
- Restaurant menu interface
- About and informational pages
- Blog section
- Interactive JavaScript behavior
- Organized image and asset structure
- Public Netlify deployment

- **JavaScript** — client-side interaction
- **Netlify** — deployment

## What I learned

This project taught me that front-end development is not just about making a page look good. Layout decisions affect navigation, readability, and usability, and those decisions often behave differently on a phone than on a desktop.

I worked through the full front-end workflow: structuring pages, organizing assets, building responsive layouts, adding interaction, testing across screen sizes, and deploying the finished site.

## Future improvements

If I continue the project, I would focus on:

- More thorough accessibility testing
- Performance optimization
- A functional reservation flow
- More interactive menu behavior
- Analytics and user-behavior insights
